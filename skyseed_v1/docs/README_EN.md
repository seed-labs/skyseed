# Documentation map

Start with `operations/environment_and_running_EN.md` when installing, moving, or
running a standalone v1 checkout, including when handing the project to a new
Codex on another host.

- `migration/` contains baseline evidence and structural-refactor gates.
- `architecture/` documents stable module ownership and dependency decisions.
  Its `design_backlog_EN.md` preserves discussed but deferred directions without
  turning them into commitments or validation gates.
- `operations/` contains environment/setup guidance, the host migration audit,
  current run policy, current validation status, and expensive-run gates;
  obsolete incident guards do not remain executable here.
- Future `guides/` documents user-facing composition and extension APIs.
- Future `history/` preserves durable experiment conclusions and retired-route
  provenance without making them active implementation guidance.
