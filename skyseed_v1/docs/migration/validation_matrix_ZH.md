# 结构迁移验证矩阵

默认门禁按影响范围选择；长跑不是所有变更的统一要求。

| 变更范围 | 必需廉价证据 | 升级条件 |
|---|---|---|
| 仅包/文档 | 导入、结构测试、旧回归套件 | 无 |
| 一个纯模型 | 归属单元测试 | IR 改变时加契约测试 |
| IR 或序列化 | 单元 + 契约夹具 + 指纹比较 | 有界重放 |
| 拓扑/规划 | 单元 + 契约 + 预览/冻结生产者比较 | Stage 3 完整有序重放 |
| 编译器 | 单元 + 后端计划比较，不写主机 | BPF-owned 时离线原生编译 |
| 运行时生命周期 | 单元 + 集成 + successor 状态有序重放 | 进程生命周期变化时系统测试 |
| 后端执行 | 单元 + 失败语义 + 离线编译/探测 | 限定主机/系统测试 |
| 可观测性/审计 | 报告真值表 + 产物契约 | 必要时重放真实不可变产物 |
| CLI/示例 | 生成选择/命令比较 + dry run | Stage 7 前不真实运行 |
| 多个 runtime/backend 或规模/计时 | 全部相邻廉价门禁 | 显式许可后才做标准长跑 |

## 测试层级

- `unit`：单模块，无 Docker/主机/网络副作用；
- `contracts`：稳定 IR 形状、序列化、指纹和失败关闭规则；
- `integration`：有界进程内或子进程模块交接；
- `replay`：不可变已准备数据按真实生命周期顺序消费；
- `system`：显式参与 Linux/BPF/Compose 环境；
- 长跑验收：单独授权的稀缺验证表面。

历史事故测试只有表达当前稳定不变量时才保留；重复的轮次断言和旧私有路径断言不构成迁移要求。

## 长跑门禁

标准长跑前记录：

1. 准确 profile、命令、输出目录、Skyseed commit 和 SEED commit；
2. 全部单元、契约、集成、重放和离线 BPF 结果；
3. 生产者、首个消费者、后续消费者及 no-op/consumed/retired/failure 覆盖；
4. 四个 horizon 的冻结输入覆盖；
5. 对陈旧/污染产物的阻断；
6. 禁止工作检查：完整运行时重生成、意外挂载/重绑定、Linux 转发回退、过早 active flip 或隐藏修复；
7. 已接受剩余风险。任何可能在后期导致正确性失败的问题都会阻止运行。
