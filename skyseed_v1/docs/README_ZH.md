# 文档地图

安装、迁移或运行独立 v1 检出时，请先阅读 `operations/environment_and_running_ZH.md`；把项目交给另一台主机上的新 Codex 时也从这里开始。

- `migration/` 保存基线证据和纯结构重构门禁；
- `architecture/` 记录稳定的模块归属和依赖决策，其中 `design_backlog_ZH.md` 保存已经讨论但暂缓的方向，不把它们变成承诺或验证门禁；
- `operations/` 保存环境与安装说明、主机迁移审计、当前运行策略、当前验证状态和昂贵运行门禁；已经过时的事故保护规则不会继续在这里执行；
- 未来的 `guides/` 用于面向用户的组合与扩展 API；
- 未来的 `history/` 用于保存长期有效的实验结论和退役路径来源，但不把它们作为当前实现指南。
