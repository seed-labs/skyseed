# Skyseed v1 测试层级

人类通常直接运行：

```bash
python skyseed_v1/tests/run.py
```

也可用 `python skyseed_v1/tests/run.py unit`、`contracts` 或 `integration` 只运行一个廉价层级。CI 和内部自动化可以等价地使用 unittest discovery；短入口文件只负责操作便利和可见性。

测试跟随模块归属，而不是历史实验轮次：

- `unit/`：单模块确定性行为，不使用 Docker、不修改主机、不访问网络、不启动长驻进程；
- `contracts/`：序列化 IR、指纹、后端归属、冻结数据和失败关闭不变量；
- `integration/`：包边界、CLI 转发、示例和 SEED 适配器导入之间的协作；
- `replay/`：有界消费已提交或显式选择的冻结运行产物，仅在夹具足够小且稳定时增加；
- `system/`：真实内核、容器、BPF 或主机生命周期检查，永不进入默认廉价门禁。

迁移工作区周边的 792 个测试仍可作为可选历史回归套件，但独立 v1 检出不依赖它们。已退役执行路径的测试应删除，而不是作为兼容门禁保留；也不会整批复制，因为其中很多编码了旧路径或特定实验轮次。实现归属迁移且断言能表达为稳定行为时，测试才随之迁移。Stage 7 会退役路径断言，并显式记录仍有价值的昂贵/系统测试。
