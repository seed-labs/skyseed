# 工具

离线分析、转换和基准命令位于这里。工具可以使用公开 Skyseed API，但生产模块绝不能导入工具。

结构切换前先对历史命令分类：

- `analyze_*`、`inspect_*`、`summarize_*`、`diagnose_*`：离线工具；
- `bench_*`：显式选择的基准，不作为验收门禁；
- `replay_*`、`check_*`：基于包 API 的审计或重放前端；
- 目录/预览构建器和抓取器：数据准备工具；
- `run_*`、预检和会话命令：受支持的 CLI 或运维前端。

只有输入/输出契约稳定的命令才会迁入。历史一次性脚本应保留在 Git 历史或文档历史中，不能仅因基线里存在就晋升为包代码。

`ground_presets/s5_operational_clean/` 是可复现 shell 专属数据构建器的参考：它写入已提交目录和显式资格报告，而生产模块只消费输出，永不导入该工具。
