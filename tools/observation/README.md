# Observation tools

Readers, projections, renderers and exports consume completed facts. The ordinary
entry remains `tools.write_experiment_tools`; direct imports/commands use
`tools.observation.*`. See the [Tool index](../README.md).

[Traffic generation](../generation/traffic/README.md) separately owns workload planning and sending.
Opening a page does not rerun Models, begin measurement or invoke
[development checks](../development/README.md). Local arrangements retain their
available data and unknown end-to-end reachability.
