# Validation Evidence

Files in this directory are historical snapshots tied to the code and names
that existed when each validation was run. Older reports may therefore contain
retired API names or paths; they are not current import or architecture
documentation.

Use `docs/CURRENT.md`, `docs/architecture/` and current source/tests for the
active package layout and public API.

The current dependency-boundary validation is recorded in
`simulator-input-dependency-boundary-validation.md`.
