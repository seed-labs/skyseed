# Physical Models

Position, Zone membership and PhysicalLink are separate replaceable roles.
Defaults implement circular orbital positions, rectangular membership and
[geometric links](links/README.md). They live with their owner; default assembly
lives in Simulator. S5's physical Model remains beside that example.

The [single role table](../../../../../docs/development/model-interfaces.md) links each minimum
contract to its template, default and example. Optional identity, geometry,
prediction and diagnostics are capabilities, not extra requirements for author Models.
