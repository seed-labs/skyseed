# Linux

`translation.py` prepares native IPv4 operations from shared Compiler intentions.
`materials.py` owns their detached contract; `runtime.py` binds them for the shared
Runner, and `runtime_command.py` executes them through retained namespace sockets.
Native `/2` materials carry supported full-path/local route bindings as well as empty
outcomes. Policy expressions outside the native contract reject offline.

`network.py` supplies shared owned namespace, dummy and veth primitives. `netlink.py`
supplies link, address, qdisc and exact owned route operations. `bpf.py` and `elf.py` remain low-level
BPF mechanisms used only by the BPF adapter; Linux native execution never loads them.
